## Juego de ejemplo: Recolector de Monedas

1. Abrí Roblox Studio y creá un lugar nuevo (Baseplate).
2. En el Explorer, creá un `Script` dentro de `ServerScriptService`.
3. Pegá el contenido de `src/ServerScriptService/JuegoMonedas.server.lua`.
4. Presioná Play: aparecen 20 monedas y cada una que tocás suma 1 punto en la tabla de jugadores.
